# Nexora Studio

Nexora Studio is a SaaS operating system for digital studios and agencies.

## Product
Create and manage client websites, Telegram Mini Apps, catalogs, leads, bookings, CRM and analytics from one workspace.

## Design direction
Modern agency SaaS dashboard with top metric widgets, clean cards, compact navigation and mobile-first responsive behavior.

## Roadmap
- Studio dashboard
- Client projects
- Website builder
- Telegram Mini Apps
- Catalog
- Leads / Inbox
- CRM
- Bookings
- Analytics
- Integrations
- Billing
